# 🧩 Maze Solver using A* Search Algorithm

## 📋 Overview
This project implements an **A* (A-Star) search algorithm** to find the shortest path through a maze/grid from a start point to a goal point. It features both console-based and graphical visualization of the search process and final path.

## ✨ Features
- 🔍 **A* Search Algorithm** with configurable heuristics (Manhattan/Euclidean)
- 🎨 **Visual Representation** using matplotlib
- 📊 **Real-time Search Visualization** showing explored nodes
- 🚧 **Wall/Obstacle Support**
- 📏 **Path Length Calculation**
- 🚫 **Unreachable Case Handling**
- 🎯 **Multiple Example Mazes**
- 📝 **Detailed Console Output**
